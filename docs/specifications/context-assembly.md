# 仕様書: 見出し・節とコンテキスト生成

本書は Markdown 化された文書から見出しを抽出し、節を選択してコンテキストへ出力する仕様を定義する。

---

## 1. 見出しの抽出

### 1.1 対象

ATX 見出し（行頭の `#`〜`######`）を対象とする。Setext 見出し（`===` / `---` の下線）は、変換器が生成しないため対象外とするが、外部から取り込んだ Markdown に含まれる場合は Setext として解釈する。

### 1.2 見出しの識別子

抽出順に `S1`, `S2`, … の識別子をセッション内で文書ごとに振る。識別子は文書の内容が同一である限り再現する。

### 1.3 見出しの属性

各見出しは、レベル、テキスト、節の開始行、節の終了行、節の文字数、子見出しの有無を持つ。

### 1.4 コードブロック内の除外

フェンス付きコードブロック内の行頭 `#` は見出しとして扱わない。フェンスの開始・終了は ```` ``` ```` および `~~~` を認識し、info string の有無を問わない。

### 1.5 重複見出し

同一テキストの見出しが複数ある場合も別の節として扱う。表示時は識別子で区別できるため、連番の付与や改名は行わない。

---

## 2. アウトライン表示

### 2.1 表示深度

既定は h1〜h3（深度 3）。深度は 2〜4 の範囲で変更でき、深度 `n` は h1〜h`n` を表示対象とする。深度を超える見出しは表示せず、件数のみを注記する。

### 2.2 表示形式

1 行 1 見出しとし、識別子・レベル・テキスト・節の文字数を表示する。階層はレベルに応じたインデントで表現する。文書ごとにヘッダ行（識別子・タイトル・URL・変換警告の有無）を出力する。

### 2.3 節の文字数

節の文字数は、見出し行を除く節本文の文字数とする。末尾の空白と空行は数えない。

### 2.4 見出しが存在しない場合

見出しが 1 つも抽出できない場合は、アウトラインの代わりに「見出しが見つからない」旨と本文の文字数、および本文全体を読むための選択肢（`S0`）を表示する。`S0` は文書全体を指す予約識別子とする。

### 2.5 目次の重複排除

同一文書内で同一レベル・同一テキストの見出しが連続する場合でも統合しない。表示順は文書内の出現順を維持する。

---

## 3. 節の抽出

### 3.1 節の範囲

節は見出し行から始まり、次の見出しの直前までとする。次の見出しのレベルが同じか浅い場合は節を終了し、深い場合は子孫として節に含める。

### 3.2 子見出しの扱い

既定では子見出しの本文も含める（`--no-children` で除外）。除外時は、子見出しの存在と件数を注記する。

### 3.3 見出し行の扱い

節本文には見出し行を含める。出力ヘッダにも見出しテキストを表示するため、本文中の見出しは階層を保つための情報として残す。

### 3.4 複数指定

複数の節が指定された場合は、指定順に出力する。同一文書内の節は文書の出現順に並べ替える（読み順を保証するため）。異なる文書間では選択順を維持する。

### 3.5 重複・包含の解決

親節と子節が同時に指定された場合は、親節に含まれる子節の出力を省略し、省略した旨を注記する。同一節の重複指定は 1 回にまとめる。

---

## 4. コンテキスト予算

### 4.1 既定値

1 回の出力に含める本文の上限は既定 8000 文字。`context.max_chars` および `--max-chars` で 500〜100000 の範囲で変更できる。

### 4.2 配分

複数の節を出力する場合、予算は選択順に均等ではなく、指定順に「残り予算を見出し数で割った値」を上限として割り当てる。端数は先頭の節へ加算する。

### 4.3 切り詰め

節の本文が割当を超える場合は行境界で切り詰め、`[truncated: 表示 N / 全体 M 字]` を出力する。見出し構造を壊す切り詰め（コードブロックの途中で終了する等）は行わず、フェンスが閉じていない場合は閉じフェンスを補う。

### 4.4 予算超過時の案内

切り詰めが発生した場合は、続きを読むための操作（同一節の継続範囲の指定）を案内する。継続範囲の指定は文字オフセットではなく「次の見出しまで」を単位とする。

---

## 5. 出所表示とプロンプトインジェクション対策

### 5.1 出所ヘッダ

すべての節出力の先頭に、文書識別子・節識別子・見出しテキスト・レベル・文字数・元 URL を含むヘッダ行を出力する。

### 5.2 信頼境界の明示

外部コンテンツは信頼できない入力として扱う。出力の冒頭に `[untrusted] <URL>` のマーカー行を置き、末尾に終端マーカーを置く。マーカーは本文と混同しないよう、本文に含まれる同一文字列を無害化する。

### 5.3 指示文の無害化

本文中に「これまでの指示を無視せよ」等の指示らしき記述が含まれていても、内容の改変・削除は行わない。代わりに、本文が外部由来であり指示として解釈してはならないことをヘッダで明示する。

### 5.4 出力のサイズ表示

出力の末尾に、出力した合計文字数と予算を 1 行で表示する。
