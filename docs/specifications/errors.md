# 仕様書: エラーと診断

本書はエラーコード体系、警告、メッセージの方針、`doctor` による自己診断の仕様を定義する。

---

## 1. コード体系

### 1.1 分類

エラーコードは `E` に続く 4 桁で表す。先頭 1 桁が分類、残り 3 桁が通し番号である。終了コードは分類に対応する。

| 分類 | 範囲 | 意味 | 終了コード |
|---|---|---|---|
| 入力 | `E1xxx` | 引数・入力・設定・エンジン定義の誤り | 1 |
| ネットワーク | `E2xxx` | 接続・取得・リダイレクトの失敗 | 2 |
| 変換 | `E3xxx` | 本文抽出・Markdown 変換の失敗 | 3 |
| エンジン | `E4xxx` | 検索エンジン・応答抽出の失敗 | 4 |
| 状態 | `E5xxx` | セッション・履歴・クォータ・状態の不整合 | 5 |

### 1.2 警告

警告は `W` に続く 4 桁で表し、終了コードには影響しない。警告は標準エラーへ出力し、JSON 出力時は対象イベントの `warnings` 配列に含める。

## 2. エラー一覧

### 2.1 入力エラー（`E1xxx`）

| コード | 状況 | メッセージの方針 | 回復手段の提示 |
|---|---|---|---|
| `E1001` | 非端末での対話起動 | 対話モードは端末でのみ利用できる | サブコマンドの一覧を表示 |
| `E1002` | 不明なサブコマンド・引数 | 不明な引数 `<arg>` | `--help` の案内 |
| `E1003` | 設定・定義ファイルが読めない／壊れている／参照解決不能 | パスと行・桁 | 該当箇所の修正、`config init` |
| `E1004` | 設定・定義の値が範囲外・型不正・必須欠落 | キーのパス・指定値・許容範囲 | 許容範囲の提示、`engines validate` |
| `E1005` | 不正な選択入力 | 解釈できない指定 | 受け付ける形式の提示 |
| `E1006` | 対象識別子が現行セッションに無い | 識別子が見つからない | 利用可能な識別子の一覧 |
| `E1007` | 検索語が空 | 検索語が空である | 検索語の入力を促す |
| `E1008` | テンプレート変数が未知 | 未知の変数名 | 使用可能な変数の一覧 |

### 2.2 ネットワークエラー（`E2xxx`）

| コード | 状況 | メッセージの方針 | 回復手段の提示 |
|---|---|---|---|
| `E2001` | 接続失敗（DNS・拒否） | ホスト名と理由 | 別の結果の選択、時間を置いた再実行 |
| `E2002` | タイムアウト | 経過時間と設定値 | タイムアウト値の変更 |
| `E2003` | HTTP エラー応答 | ステータスコード | 4xx は別 URL、5xx は再試行 |
| `E2004` | リダイレクト過多・ループ | 追従回数と最終 URL | 元 URL の確認 |
| `E2005` | 非対応スキーム・非 HTML | Content-Type とスキーム | 対応形式の提示 |
| `E2006` | robots.txt による拒否 | 該当ルール | 別 URL の選択 |
| `E2007` | 応答サイズ超過 | 上限値 | 上限設定の変更 |
| `E2008` | TLS 検証の失敗 | ホスト名と理由 | CA 設定の確認（`tls.caFile`） |

### 2.3 変換エラー（`E3xxx`）

| コード | 状況 | メッセージの方針 | 回復手段の提示 |
|---|---|---|---|
| `E3001` | 本文が抽出できない | 抽出後の文字数 | 本文全体を対象にした再試行 |
| `E3002` | 非対応形式（PDF 等） | Content-Type | 別の結果の選択 |
| `E3003` | 文字コード判定の失敗 | 判定に用いた情報 | 文字化けの可能性の注記 |
| `E3004` | Markdown 変換の失敗 | 失敗した要素の種類 | 抽出方式の変更 |

### 2.4 エンジンエラー（`E4xxx`）

| コード | 状況 | メッセージの方針 | 回復手段の提示 |
|---|---|---|---|
| `E4001` | 結果が 0 件（抽出結果を含む） | 検索語とエンジン ID | 検索語の修正、別エンジン |
| `E4002` | エンジンが利用不能（無効・認証情報不足・定義不備） | 不足している項目 | 設定方法、`engines list` |
| `E4003` | レート制限・拒否（429・403 等） | 応答コードと待機時間 | 待機後の再実行、エンジン変更 |
| `E4004` | 応答の解析失敗（抽出ルール不一致） | 応答の先頭テキスト | `engines test` でのセレクタ修正 |
| `E4005` | エンジン定義の重複 ID | 重複した ID とパス | 定義の整理 |
| `E4006` | 抽出規則の適用結果が不正（相対 URL など） | 破棄した件数 | `absolutize` 変換の追加 |

### 2.5 状態エラー（`E5xxx`）

| コード | 状況 | メッセージの方針 | 回復手段の提示 |
|---|---|---|---|
| `E5001` | セッションが存在しない・期限切れ | 指定した識別子 | 新規セッションの開始 |
| `E5002` | 状態ディレクトリに書き込めない | パスと理由 | 権限・容量の確認 |
| `E5003` | 同時更新の衝突 | 対象セッション | 再実行 |
| `E5004` | 履歴ファイルの破損 | 読み飛ばした行数 | `export` による退避と再作成 |
| `E5005` | クォータ超過 | 項目名・上限・消費量・リセット時刻 | 待機、ポリシー変更、`quota reset` |

| `W2001` | レート制限のため待機した | 待機時間 |
| `W3001` | 本文推定に失敗し全体を変換した | 変換方式の切替 |
| `W3002` | 描画不足の可能性 | JavaScript 依存の可能性 |
| `W3003` | 応答サイズの打ち切り | 打ち切り位置 |

## 4. メッセージの方針

### 4.1 構成

エラーメッセージは「何が起きたか」を 1 文で示し、続けて「なぜか」「どうすればよいか」を箇条書きで示す。原因が不明な場合は推測を断定しない。

### 4.2 言語

既定は日本語（`ui.locale=ja`）。`en` を指定した場合は英語で表示する。コードと JSON のフィールド名は言語に依存しない。

### 4.3 出力先

エラーと警告は常に標準エラーへ出力する。JSON モードでも標準エラーへ人間向けの文言を出し、標準出力の JSON にはコードと定型メッセージを含める。

### 4.4 秘匿情報

メッセージに API キー・Cookie・認証ヘッダを含めない。URL は秘匿パラメータを伏字化して表示する。

## 5. `doctor` による自己診断

### 5.1 診断項目

`doctor` は次の項目を順に確認し、各項目を成功・警告・失敗で表示する。

1. 実行環境（版数、OS、Rust のビルド情報）
2. 状態ディレクトリの存在・権限・空き容量
3. 設定ファイル（4 種）の探索結果と検証結果
4. エンジン定義の検証（全件。失敗があれば該当 ID を列挙）
5. 選択エンジンの認証情報の有無
6. ネットワークプロファイルの妥当性と到達性（HEAD 要求を 1 回）
7. robots.txt 取得の可否
8. クォータの残量と適用ポリシー
9. 履歴・セッションの件数と容量

### 5.2 結果の表示

各項目は 1 行で `[ok]` / `[warn]` / `[fail]` を先頭に付け、失敗項目には次の操作を提示する。`--json` 指定時は `diagnostics` イベントで診断結果の配列を出力する。

### 5.3 ネットワーク診断の制約

到達性の確認は外部への小さな要求に限定し、検索クエリの送信は行わない。診断は既定で 1 回のみ実行し、再試行ループを行わない。診断による通信はクォータを消費するが、`searches` ではなく `fetches` として計上しない（`quota` の対象外であることを明示する）。
