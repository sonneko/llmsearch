# 仕様書: コマンドラインインターフェース

本書は `llmsearch` の起動方法、対話メニュー、非対話サブコマンド、出力チャネル、入力規則を定義する。

---

## 1. 起動とモード

### 1.1 起動形態

引数なしで起動した場合は対話モードとなる。サブコマンドを指定した場合は非対話モードとして 1 操作を実行して終了する。対話モードでも同一の操作が内部的に実行される。

### 1.2 モード判定

標準入力が端末でない場合、対話モードは起動せず、エラー（`E1001`）を返して非対話サブコマンドの利用を促す。標準出力が端末でない場合でも動作は変えず、番号メニューは標準エラーへ出力する。

### 1.3 共通オプション

| オプション | 既定 | 説明 |
|---|---|---|
| `--json` | 無効 | 標準出力を JSON イベント形式にする |
| `--session <id>` | 自動採番 | 既存セッションを継続する |
| `--engine <id[@variant]>` | 設定値 | 検索エンジンを一時的に切り替える |
| `--network <id>` | 設定値 | ネットワークプロファイルを一時的に切り替える |
| `--filters <id>` | 設定値 | フィルタ集合を一時的に切り替える |
| `--quota <id>` | 設定値 | クォータポリシーを一時的に切り替える |
| `--no-filter` | 無効 | 結果・本文フィルタを無効化する（`all` を付すと既定の除去要素も無効） |
| `--no-cache` | 無効 | キャッシュの読み書きを行わない |
| `--refresh` | 無効 | キャッシュを無視して再取得する |
| `--config <path>` | 既定の探索順 | 設定ファイルを明示指定する |
| `--state-dir <path>` | 設定値 | 状態ディレクトリを明示指定する |
| `--engines-dir <path>` | なし | エンジン定義の追加探索ディレクトリ（複数指定可） |
| `--no-color` | 自動判定 | 装飾を無効化する |
| `--quiet` | 無効 | 進捗表示を抑制する |
| `--verbose` | 無効 | 診断情報を標準エラーへ追加する |
| `--help` / `--version` | — | 使用方法・版数を表示して終了する |

## 2. 対話モードのメニュー

### 2.1 検索結果メニュー

検索直後に、結果一覧と次のメニューを表示する。番号は仕様として固定であり、項目の入れ替えを行わない。

```text
Q: 気候変動 適応策            engine: duckduckgo   表示: 1-7 件目

[R1] 気候変動適応情報プラットフォーム
     https://example.jp/adaptation
     国の適応計画と地域の取組事例をまとめたポータル。…
[R2] …

  1) 終了
  2) 検索結果の選択（複数可）
  3) 8 件目以降を見る
  4) 検索ワードを修正する
>
```

- **1) 終了**: セッションを閉じ、終了コード `0` で終了する。
- **2) 検索結果の選択**: 選択用の入力待ちへ移る（§2.2）。選択後は文書取得とアウトライン表示へ進む。
- **3) 8 件目以降を見る**: 次のページを取得して追記表示する。取得済みの結果は再表示せず、識別子は連番を継続する。フィルタ適用後の件数と除外件数を 1 行で示す。
- **4) 検索ワードを修正する**: 現在の検索語を初期値として編集入力させ、新しい検索を実行する。以前の結果一覧はセッション内に保持し、履歴から再参照できる。

### 2.2 結果選択の入力規則

- 受け付ける形式: 単一番号 `3`、複数指定 `1,3`、範囲 `1-3`、識別子 `R1,R3`、混在 `R1,3-4`。
- 区切り文字はカンマ、空白、読点のいずれも受け付ける。
- 空入力はキャンセルとして扱い、検索結果メニューへ戻る。
- 存在しない番号、範囲外、重複は警告を出して再入力させる。3 回連続で不正な場合はメニューへ戻る。
- 選択順は読み取り順として保持し、アウトラインの表示順に反映する。

### 2.3 アウトライン・メニュー

選択された結果を取得・変換し、各文書の見出し（既定 h1〜h3）を表示した後に次のメニューを表示する。

```text
[D1] 気候変動適応情報プラットフォーム   https://example.jp/adaptation
  S1  h1  気候変動適応情報プラットフォーム                        (920 字)
    S2  h2  1. 気候変動影響評価                                 (2,140 字)
    S3  h2  2. 適応計画の策定                                   (3,560 字)
      S4  h3  2.1 地域適応計画                                  (1,240 字)
[D2] …

  1) 終了
  2) 節を選んで読む（複数可）
  3) 見出しの表示深度を変更する
  4) 検索結果一覧に戻る
  5) 履歴を見る
>
```

- **2) 節を選んで読む**: `D1:S3` 形式、または `S3`（単一文書の場合）で指定する。複数指定可。指定順に本文を出力する。
- **3) 見出しの表示深度を変更する**: 2〜4 の範囲で再指定し、同じ文書のアウトラインを再表示する。再取得は行わない。
- **4) 検索結果一覧に戻る**: 取得済み文書と選択状態を保持したまま、検索結果メニューへ戻る。
- **5) 履歴を見る**: 直近の履歴を表示し、そのまま節の再出力やセッションの再開へ進める。

### 2.4 節本文の表示形式

節本文は、出所が分かるヘッダ行と、信頼できない外部コンテンツであることを示すマーカーの後に出力する。

```text
--- D1:S3 | 2. 適応計画の策定 | h2 | 3,560 字 ---
[untrusted] https://example.jp/adaptation
<節の Markdown 本文>
--- end ---
```

予算超過で切り詰めた場合は、末尾に `[truncated: 表示 8000 / 全体 12000 字]` の形式で、表示した字数と全体の字数を 1 行出力する。見出しの階層を保つため、切り詰めは行境界で行う。

### 2.5 通常の情報行

対話モードでは、操作の結果を 1 行で示す。表示するのは次の情報である。

| 状況 | 表示例 |
|---|---|
| 検索後 | `検索 7 件（フィルタ除外 5 件） / searches 13/50 (session)` |
| 取得後 | `取得 D1 4,200 字 / fetches 9/100 (session)` |
| 上限到達 | `上限に達しました: day.searches 500/500（リセット 2026-11-08 00:00）` |

### 2.6 中断と復帰

`Ctrl+C` は現在の入力を取り消してメニューへ戻る。メニューで 2 回連続して `Ctrl+C`、または `1) 終了` で終了コード `0` を返す。`Ctrl+D`（入力終端）は終了として扱う。

## 3. 非対話サブコマンド

### 3.1 コマンド一覧

| コマンド | 目的 | 主なオプション |
|---|---|---|
| `search <query>` | 検索して結果一覧を出力する | `--limit`, `--page`, `--engine` |
| `next` | 同一クエリの次ページを取得する | `--session` |
| `refine <query>` | 検索語を変更して再検索する | `--session` |
| `outline <target>` | 文書を取得・変換し、見出し一覧を出力する | `--depth`, `--refresh` |
| `read <target>` | 節本文を出力する | `--section`, `--heading`, `--max-chars`, `--no-children` |
| `history [list\|show\|grep\|export\|clear]` | 履歴の参照・出力・削除 | `--limit`, `--format`, `--before` |
| `engines [list\|show\|validate\|test]` | エンジン定義の参照・検証・試行 | `--query`, `--dry-run`, `--raw` |
| `network [list\|show\|validate]` | ネットワークプロファイルの参照・検証 | `--raw` |
| `filters [list\|show\|validate]` | フィルタ集合の参照・検証 | `--raw` |
| `quota [show\|reset\|check]` | クォータの参照・初期化・事前確認 | `--scope`, `--kind`, `--amount`, `--yes` |
| `config [show\|path\|init\|validate\|explain]` | 設定の表示・初期化・検証 | `--config`, `--force` |
| `doctor` | 環境・ネットワーク・設定の診断 | `--engine` |

### 3.2 対象の指定方法

`outline` と `read` の `<target>` は次のいずれかを受け付ける。

1. URL（`https://` または `http://` で始まる）
2. セッション内の検索結果識別子（`R3`）
3. セッション内の文書識別子（`D2`）
4. セッション内の結果番号（`3`）。3 と URL 以外の数値は検索結果番号として解釈する

識別子が現行セッションに存在しない場合は `E5001` を返し、利用可能な識別子の一覧を標準エラーへ出力する。

### 3.3 終了コード

| コード | 意味 |
|---|---|
| `0` | 正常終了 |
| `1` | 引数・入力・設定の誤り（`E1xxx`） |
| `2` | ネットワーク・取得の失敗（`E2xxx`） |
| `3` | 変換・解析の失敗（`E3xxx`） |
| `4` | 検索エンジン・抽出の失敗（`E4xxx`） |
| `5` | セッション・状態・クォータの不整合（`E5xxx`） |
| `130` | 割り込みによる中断 |

## 4. 出力チャネルと終了コード

### 4.1 チャネルの分離

- **標準出力**: 結果データ（一覧・アウトライン・節本文・JSON イベント）。パイプやファイルへのリダイレクト対象。
- **標準エラー**: メニュー、進捗、警告、診断。リダイレクトしても結果データを汚さない。

### 4.2 テキスト出力の規則

1 行 1 レコードを基本とし、識別子を行頭に置く。装飾（色・太字）は標準出力が端末のときのみ有効とし、`--no-color` で無効化する。

### 4.3 JSON 出力の規則

`--json` 指定時は 1 行 1 JSON オブジェクト（JSON Lines）を標準出力へ出力する。イベントの種類と必須項目はエージェント連携の仕様で定義する。エラー時も JSON を出力し、`error` イベントにコードとメッセージを含める。

## 5. キーボード・入力規則

### 5.1 入力プロンプト

- 数値メニューは 1 文字以上の数字を受け付け、Enter で確定する。前後の空白は無視する。
- 検索語の編集では、現在値を初期表示し、空入力でキャンセルする。
- 入力履歴（同一セッション内の検索語）を保持し、`!` に続けて番号を入力すると再利用できる。

### 5.2 表示幅

- タイトルは設定 `search.titleChars`（既定 100 文字）、スニペットは `search.snippetChars`（既定 120 文字）で切り詰め、切り詰め時は末尾に `…` を付ける。
- 全角文字は 2 桁として扱い、端末幅を超える行は折り返す。
- 端末幅が 60 桁未満の場合は URL を省略してタイトルのみ表示する。
